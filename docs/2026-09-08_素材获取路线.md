# 2026-09-08 素材获取路线（蜘蛛侠素材库怎么拿到手）

## 背景与问题

项目转向"固定素材库"路线：需要荷兰弟蜘蛛侠三部曲（2017/2019/2021）作为素材库。
硬约束：**本地无磁盘空间，只能在服务器下载**；服务器网络受限（历史上 github、
字节系 CDN 均被墙）。

## 候选方案

| 方案 | 思路 | 预期优劣 |
|---|---|---|
| A. 服务器流媒体直下 | yt-dlp 拉 bilibili 等站点 | 全自动，但站点可能被墙 |
| B. 磁力/BT（aria2+DHT） | 去中心化，不依赖单一站点 | 站点被墙也能用；正片涉版权 |
| C. 本地下载→scp 回传 | Phase 1 视频同款链路 | 被用户否决（本地无空间） |
| D. 官方预告片/片段 | 片方宣传物料，B站官方有 | 合法、动作密度高；体量小于正片 |

## 实测/对比

- 服务器连通性实测（curl，8s 超时）：
  - bilibili.com=000、api.bilibili.com=000、youtube.com=000、archive.org=000、academictorrents=000（全被墙）
  - releases.ubuntu.com=200、files.pythonhosted.org=200、hf-mirror/modelscope=通（既有结论）
- **B 方案可行性验证**：aria2c（系统已有）+ Ubuntu 22.04 官方种子实测 90 秒——
  tracker/DHT 全通，peer 连上、数据实际下流（45KiB/s 起步）。**基础设施成立。**
- 正片磁力检索：搜索层对版权电影磁力**拒答**，无法提供链接（方案 B 对正片受阻于来源获取，非技术）。
- D 方案实测：本地（Windows）bilibili=302 通 → 本地 yt-dlp（2026.08.19）搜官方预告，
  12 条候选人工筛掉 3 条"老外反应视频"，**9 条/294MB**（含 1080P 预告合集）落地，
  scp 上服务器后本地即删。B站搜索页结构：BV 号在 href、标题在 h3 title、UP主在
  title="UP主：…"，搜索 API 需 wbi 签名（未走）。

## 选择与理由

**D（官方预告片库）先行 + B（磁力）保留**：D 零版权争议、当天可用、预告片本身是
高密度剪辑素材（9 条切出 593 镜头，B1 实测）；B 的基础设施已验证可用，正片若
用户提供自有来源（自购蓝光 rip/自有网盘链接/磁力）随时可挂 aria2 后台下。

## 结果

- 9 条预告片入库 `data/library/raw/trailers/`，B1 切分 593 镜头（83/85/70/29/51/61/62/80/72）
- 正片三部曲：**待用户提供获取渠道**（技术链路已就绪）

## 从结果学到什么

- "站点被墙"不等于"下不了"——去中心化网络（DHT）单测通过即可信；
- 搜索页 HTML 解析比签名 API 稳（wbi 签名会变，DOM 结构相对稳定）；
- 素材库起步不必等正片：预告片 593 镜头已够 V0 检索/装配验证跑通。
