# 2026-09-10 7682 型情感叙事模板 MVP：文案轨 / BGM / 短时长

## 背景

用户看完叙事库 v6 成片：「不知道想表达什么，什么也没剪的感觉」，并指出想要
「剪成和 7682719919410072847（良田·无手青年跆拳道奇迹，62.5万赞）类似的」。

## 7682 解剖（帧级 + 逐帧 OCR 实测）

- 21.9s 竖屏，**只有 3 个长镜头**（7/7/8s），零快剪——表达力不在剪辑在文字轨
- 文案结构：钩子断言「人们常常觉得失去了双手 就会变成一个废人」（0-4.2s 压在握手
  画面）→ 比赛实证留白 → 成就卡连发（跆拳道全国冠军/用脚代手吃饭洗澡…，17.8-20.9s
  ~1s/张）→ **反转梗收尾「但不会剪脚指甲」（21.9s）**
- 音轨只有 BGM（SenseVoice 无语音检出）——公式 = **弱视觉事件 + 强文字轨 + BGM**

## 管线缺口（对抗验证 4/4 成立）

| 缺口 | 证据 |
| --- | --- |
| 无文案生成层 | write_story_subtitles 只烧素材对白翻译；参考文字层在叙事模式被剔除（v5 事故） |
| 无 BGM 轨 | renderer 音频只有素材原声/静音两条路 |
| 时长锁死 45-75s | story_planner 双守卫，21.9s 类模板整类被挡 |
| 字幕时序被对白锁死 | cue 只能来自 picked.dialogue 时序映射 |

宝藏：仓库早有 LLM 文案+drawtext 烧录+铺音频模块（story.py/assemble_lib.py/
generation/assemble.py），只是叙事管线没接——本 MVP 是「接线」不是「从零造」。

## 方案对比

- **MVP 派（采纳，先出片）**：copywriter.py（模板保底+单次 ask）→ 复用 SRT 字幕
  通道烧文案；BGM 终封换轨（模板自带 BGM 提取轨，版权状态与素材一致）；时长界
  20-75；同源去重二 pass（7682 弧 hook/conflict 同引 event_002，Viterbi 相邻惩罚
  拦不住隔槽撞段）；竖屏 720x960。
- **架构派（后续）**：Presentation 层成一等公民（text_track/punchline schema）、
  叙事归纳 prompt v2（主角对账/外部证据/禁事件双角色）、归纳缓存加版本键、
  类型→关注维度路由表（用户构想，专项审计裁决现不存在）。

## 实施与验证（commit 8b18253 + 1b4ae5c，334 测全绿）

- 帧验三帧全中：钩子烧在炭治郎带血特写上；卡压雪地背祢豆子画面下 1/3；

- 成片：data/preview/library_v0/guimie_7682_mvp.mp4（本地）

## 遗留（按用户「先看质量再优化」）

1. 类型→关注维度路由表（战略件，`intent.content_type` 现为零消费死标签）
2. Presentation 层 + 归纳 prompt v2 + 缓存版本键（架构派 P1-P2）
3. 评论区外部信号接入（需 DOUYIN_COOKIE 重抓）
4. consequence 槽召回仍是安静镜头（guimie 池 0 成就类 caption，文案兜住了语义）

## 教训

- **本地 3.12 / 服务器 3.10**：f-string 嵌套同引号是 3.12+ 语法，本地全绿服务器
  SyntaxError。修复后用 `ast.parse(feature_version=(3,10))` 全仓扫描防复发。
- LLM 层必须「失败即落模板」：_GoodRunner/_BrokenRunner 双测试锚定该契约。
