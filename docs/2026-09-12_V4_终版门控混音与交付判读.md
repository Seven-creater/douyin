# 2026-09-12 V4 决策记录（二）：终版门控、混音与交付判读

## 一、audio 三态：验证依赖什么证据，交付保留什么证据

外审三轮十节原则：**素材靠对白证明合格，终版就不能把对白删掉**。V3_C3
病灶：验证时「字幕显示他们讨论危险」算 pass，交付版 -map 1:a:0 纯 BGM 替换
+ 字幕带裁切——观众拿到的版本把内容删了。

### 决策

| 状态 | 触发 | 终混 |
|---|---|---|
| `dialogue` | 空计划退化 | 素材原声 |
| `bgm` | 无任何 live 槽有 ≥2.0s 可用对白 | BGM 整轨（7682 纯文案公式，现状） |
| `mix` | 任一 live 槽可用对白（translation_zh 有效）累计 ≥2.0s | **原声 volume=1.0 + BGM mix_volume≈0.25 低混** |

ffmpeg：`[1:a]volume=1.0[ra];[2:a]volume=0.25,afade…[bg];[ra][bg]amix=
inputs=2:duration=first:normalize=0[au]`。**normalize=0 必须显式**——amix
默认 1/inputs 归一会把原声压半。原声取 concat 而非 masked（规避 mask 后端
丢音轨）；三输入布局 [0]=masked(视频) [1]=concat [2]=bgm(loop)；-vf（字幕
烧录）与 -filter_complex 并存。

### 0.25 是默认值不是事实标准（外审十节）

不同电影对白电平差异大。验收以**人耳听清对白**为准，不以 volume 数字为准。
loudnorm / sidechain ducking 记档 V4.1。

## 二、审谁就交谁：盲看输入改为终版

V3 顺序：det → 盲看（素材原声、无文案版）→ copy → 带文案终渲。盲看审的
和观众看的**不是同一产物**。V4 顺序：

```
det_final → copy+grounding（烧录前丢弃/替换）→ _re_render(final_render)
（文案+终混=真交付物）→ _release_gpu_cache → 盲看看终版 → overall
```

盲看 prompt v2 声明「画面内字幕/烧录文字属于视频内容」。B 档
（verification off）不跑盲看，overall 不因此 fail（对照臂语义）。

## 三、overall 门控（外审必改③）

`_overall_verdict(det, blind, grounding, story, blind_required)`：

```
passed = det.passed
      AND plan_complete（必选槽无 unsupported）
      AND copy 轨道达标（assertion 型：hook_line 与 punchline 均存活——
          替换可以，消失不行）
      AND blind_required ? (parsed AND consistent_protagonist is True) : True
```

**blind 开启时 None/unparsed/inconsistent 三态全部 blocked**——初版公式
`blind is None → 放行` 是逻辑 bug（没跑成的盲看比失败的盲看分数还高），
实现前修正（外审十节直接点名）。

失败仍产出视频（调试预览），但 `manifest.stage("delivery", "blocked",
reasons=…)`、final_review.overall.passed=False。**交付判读以
final_review.overall 为准**，「机器指标全绿」的表述自此作废。

### re_search_log：提出 ≠ 采用

V3_C3 实锤：日志记 slot2「replaced→5100s」，终稿仍 2775s（critic 通道在
deepcopy 副本上重搜，分数不升 break 在采用之前，替换被丢弃但已记日志）。

重渲，恒 True。

## 四、验证解析硬化（外审六节）

parse_verification 规整层（代码保证，不信模型自我汇报）：
- met=true 必须带合法 evidence_interval（二元数值、0≤start<end），否则
  met=false；
- verdict=pass 但存在 met=false 或 missing 非空 → 降级 fail（记
  `normalized: pass with unmet conditions`）；
- fail 且 missing/failure_reason 皆空 → 补 unspecified；
- verify_slots 主循环追加越界检查（模型报绝对时间/越界秒数 → 该条件打回，
  `normalized: evidence outside clip`）。

## 五、copy grounding 补洞（外审六节）

- hook_line 此前零检查原样保留 → 补检：断言型钩子与首 live 槽 caption 零
  shingle 重合 → 换无断言兜底钩（report.replaced_hook）。
- `_IDENTITY_ASSERTION_CHARS`（才是/变成/原来我们/属于/从不/总是/永远）
  并入 punchline 检查——「原来我们才是异类」「人类从不真正接纳妖怪」类
  判断句需要画面支撑；兜底钩「人们常常觉得…」不含标记词不受影响。
- 卡片收紧：共享 ≥2 shingles（单 token 卡豁免）。

**记档 V4.1 不做**：copy → verified evidence 消费（verification 输出
observed_facts 供 copywriter 引用，替代 caption 自证——外审八节指出 caption
本身可能就是错的）。

## 六、pack validity gate（外审必改①，本轮不重跑 bootstrap 的保护）

film2 旧 pack 的代表帧塌缩在 [90.1, 90.9]s（duration 读取双层信封错位 →
恒 0 → 采样区间 [90,91]）。本轮不重跑 pack（pack_sha 变会击穿 36 窗
resume_key，与「72 窗重标下一轮」拍板冲突），但 `pack_validity` 在
annotation_view 注入点拦截：timestamps 非空时 span < 300s → invalid → 不注入
（退回 V3 pure perception）+ logger warning。timestamps 为空 = 人物帧路径
（film1 实际生效路径，帧跨全片）放行。新 pack 的 provenance 记
duration_source（ffprobe 主读链，全空显式 raise——静默塌缩比崩溃恶劣）。
