# 2026-09-12 P1.5 Film Knowledge Bootstrap：设计与五轮冒烟实录

## 动机

V3（主体契约+双层验证+文案 grounding）后成片仍被**素材标注层**拖累：Omni 逐窗
看片人物识别不可靠（无限 →"黑发持刀少年/黑发少女"，同角色跨窗 entity_id 漂移），
caption 层因"禁 IP 常识"只能写外观。外审方案：看片前先建世界模型（coding-agent
先知 repo 再开文件）。

## 核心设计（外审二轮修订全部落实）

1. **两层 Identity 永不合并**：标注 entity_ids 永远本地 `vis_` + bindings 旁挂
   canonical（status/confidence/evidence；白名单防自造 canonical）——pack 认错
   只改 binding，视觉观察层无损可审计。
2. **Identity Gate 二次独立投票**：帧 A/B 两组各自识别；agreement+平均置信+
   元数据佐证定档；模型与元数据矛盾 → identity_conflict 不注入。
3. **annotation_view 只放 Recognition Prior**（roster/aliases/appearance）；
   关系/剧情是 Narrative Prior 绝不进标注器。
4. 状态机 proposed→supported→**verified（只认独立 GT，防循环论证）**/conflict/
   unobserved；source_entities 回填 auto registry（不覆盖手写表）。
5. 搜索可插拔默认禁用；产品/实验双模式（--mask-metadata 控泄漏源）。

## 最终冒烟结果（luoxiaohei1）

```
tier: metadata_prior | title: 罗小黑1（从文件名提取）
entities（全 proposed，source=metadata_prior）:
  罗小黑 | 小黑 | 黑色短毛猫/白色肚皮/圆耳
  无限   | 无限大人 | 白发/长袍/手持法杖   ← 模型记忆混淆（实际黑发执行人）
  风息   | 老猫 | 灰白长毛/独眼/伤疤       ← 同样存疑
```

先验错误（"白发无限"）正是 to_verify+绑定层存在的理由：标注时画面特征
（黑发/执行人制服）与候选外观不符 → binding=conflict，先验压不过视觉。

## 研究发现（顺带）

**Known-arm 前提被推翻**：罗小黑对 Qwen3-Omni 不是" Known Movie"——视觉识别
四轮全拒认（角色帧也拒）。三臂实验的 Known 臂实际测的是 metadata_prior 路径；
"模型背剧情"的泄漏担忧在这个模型+这部片上暂时不成立，反而暴露检索依赖。
（Parametric 视觉识别能力 ≠ 文本知识，这本身就是分臂数据。）
