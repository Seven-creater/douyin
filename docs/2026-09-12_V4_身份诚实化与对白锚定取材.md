## 一、身份诚实化（外审必改①的精神内核）

2. `source_entities`（现为**窗口作用域** `source/w{N}/{id}`）；
3. supported/verified `bindings`。
appearance_aliases / role_labels / proposed binding / 一切 canonical guess
**不进硬约束**。

## 二、对白锚定取材 + 禁止盲切（外审必改②）

### 根因链（定量核实）

film1 索引 36 条记录**全部整 45s**（镜头检测未细分；film2 有真实 2~7s 细分）
→ `_select_evidence_window` 的多镜头证据跟随选窗无细粒度可用 → 全踩
"source_start 起前 N 秒"兜底 → 45s caption 给前 7.33s 背书。dialogue 时间戳
（H1 归一）存在于标注但**从未参与选窗**。

### 设计

1. **member_shots 带 dialogue**（镜头行自带，H1 归一）。
2. 多镜头主路径联合评分：`caption_overlap + 0.5 × dialogue_overlap`
   （行归属=中点落窗内；权重 0.5 保证无对白排序与 V3 完全一致——既有测试
   `test_evidence_window_follows_relevant_shot_not_event_start` 不动仍绿）。
3. **单镜头超预算**：有相关对白 → `_anchor_by_dialogue` 镜头内锚定（lead
   让锚行完整落入；行比预算长时整行优先，≤1s 轻微超预算由渲染 -t 收口）；
   **无锚且 > 2×budget → anchor="coarse"，禁止起点盲切**。
4. **localize_coarse_slots**（新 pipeline 步骤，渲染前）：Omni watch 完整
   45s 窗输出 `{start, end, evidence}` → 改写槽区间（anchor=localized）；
   解析失败/未找到 → 槽降 unsupported → 必选槽 plan_incomplete → blocked。
   **localize or reject，不再"caption 说了就算"**。
5. 边界补全：截断的相关对白行（越界 ≤1.0s）在预算内扩到行尾。

### 代价与边界

- localize 每粗槽 +1 次 watch（45s 窗 ≈1-2min GPU）——夜间预算可容。
- 关键词锚定（shingle 重合>0）可能锚到"提到而非表现"的行——由 P3 验证器
  事后核对（验证看的就是实际进片区间）。
- 无 runner 的手动 render 路径跳过 localize 并告警（coarse 区间将按槽预算
  截断）——debug 专用通道，不进产品路径。

## 三、form→need 转换（同轮修复）

narrative_agent 弧段改双字段输出：`form_function`（固定 enum）+
`function`（自由中文说明）。compile_form_need 消费顺序：enum → legacy
关键词归一器 → 空（上层角色模板）。**红线**：need 文本永远来自模板，
绝不拼输入句原文（参考事实泄漏，C2 教训）。

legacy 词表的歧义裁定（外审十四节）：列举/成就/能力/实力/证明/认可 是
**强扩展信号**，同句出现时压过 对比/局限（"列举生活技能与局限形成对比"
→ evidence_expansion，非首段反证）。该归一器是迁移补丁，长期靠 enum。
