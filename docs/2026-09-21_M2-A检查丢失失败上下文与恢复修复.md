## 修复

- inspect 无 validator 的成功不再清空未解决的失败；Controller 获取实际
  observation。重启从当前版本 trace 恢复失败；相关资产真正验收通过才清除。
- 停滞后提供一次受限恢复机会：从当前 runnable 集选择失败资产的验证写入
  技能，优先 repair；预算、依赖和 allowed_skill_names 硬门继续生效。
  忽略限制或无可执行修复时停止，不重复 inspect。
- registry.can_run 删除覆盖 effective_status 的裸 get_status，保留依赖失效门。
- acceptance 的 master/views/human_review 以有效状态为准；失败或 stale 视图
  不推荐给下游；master 修复计入 front 修复次数。
- master 验收补充剧本原文及 anatomy/accessories 信息，禁止仅凭眼罩推断
  医学视力状态；保留年龄、身份与背景质量检查。
- 生成提示要求灰底铺满画面、灯架和纸框在画外；去除强制睁眼看镜头模板；
  repair 与首次生成均保留 anatomy/accessories 约束。
- 新增受 Git 管理的 scripts/v4_resume_m2a.py，复用原 workspace、不重新播种、
  不删除旧文件。固定 Omni 0/1、图像 worker 4/5；启动检查占用并加单实例锁，
  不使用 vLLM 的 2/3。机器终点仍为 candidate，最终锁定需要人工审核。
