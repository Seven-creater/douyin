# 工程决策记录模板

> 每个问题一个文件，命名 `YYYY-MM-DD_主题.md`。写清楚：遇到了什么问题、有哪些候选方案、
> 各方案实测结果、为什么选最终方案、结果如何、从结果里分析出什么。禁止事后美化——
> 失败数据照记。

## 背景与问题

（什么场景下遇到的什么问题，现象是什么，怎么发现的）

## 候选方案

| 方案 | 思路 | 预期优劣 |
|---|---|---|
| A | | |
| B | | |

## 实测/对比

（每个试过的方案：怎么测的、真实数据、失败样例。没测的标"未测+原因"）

## 诊断依据

（**区分假设的关键证据**：哪条数据/实验把错误假设排除、把真凶坐实。
排查链有多长、在哪一步转向——这一段回答"怎么从结果分析出问题"）

## 选择与理由

（选了哪个，为什么；关键取舍是什么）

## 验证

（**问题有没有真解决的判定**：复现路径重跑的结果、产物/指标对照、人工抽检；
判定标准是什么；哪些路径没测到、残留风险是什么。"代码改了"不算验证）

## 结果

（上线后的真实结果，含意外副作用）

## 从结果学到什么

（结论是否成立？暴露了什么新问题？对后续决策的约束）
