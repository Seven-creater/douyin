## 写作规矩

1. 实测数据照抄（失败数据也是数据），禁止事后美化；
2. 没测的方案标"未测+原因"，不许暗示测过；
3. 用户拍板的决策注明"用户拍板"，算法/工程权衡写清取舍；
4. 结果栏允许"待回填"，但阶段结束后必须回来补。
